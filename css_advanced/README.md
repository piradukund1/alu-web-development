# SmileSchool — CSS Advanced

## Description
SmileSchool is a webpage project built with HTML and CSS. The goal is to style a webpage using a design reference and practise CSS layouts, backgrounds, typography, spacing, and alignment.

## Sections
- Header and banner
- Professional profiles
- Quote section
- Popular video tutorials
- Free membership
- Frequently asked questions
- Footer

## Technologies
- HTML5
- CSS3
